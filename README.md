# Лабораторная работа №2 — Code Review

Репозиторий подготовлен для выполнения лабораторной работы по дисциплине «Технологии и методы программирования».

## Схема сдачи

- `main` — базовая ветка.
- `review-target` — исходный код, который нужно проверить.
- Pull Request создаётся вручную из `review-target` в `main`.
- Code review выполняется непосредственно в Pull Request.

Исходный код в ветке `review-target` оставлен без исправлений, чтобы замечания можно было оформить как полноценное ревью.
